# Segmento: Indústria

Dores típicas de maturidade de dados em indústrias:

- Dados de chão de fábrica (OEE, sensores, IoT) isolados dos ERPs e dos sistemas de planejamento, sem pipeline estruturado.
- Qualidade de dados mestre de produtos/materiais e cadastros de fornecedores baixa, impactando compras e MRP.
- Rastreabilidade incompleta entre ordem de produção, lotes e rastreio de qualidade (regulatórias ISO).
- Indicadores de produção calculados em planilhas, com métricas divergentes entre plantas.
- Governança de dados fraca sobre os dados gerados por máquinas e pela cadeia de suprimentos.

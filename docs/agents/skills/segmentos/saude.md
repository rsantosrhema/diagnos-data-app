# Segmento: Saúde

Dores típicas de maturidade de dados na saúde:

- Prontuários e dados clínicos em sistemas legados e formatos não interoperáveis.
- Qualidade e completude dos dados de pacientes (duplicidade, dados desatualizados).
- Conformidade e privacidade (LGPD/ANPD) exigem controle rígido de acesso e rastreabilidade.
- Indicadores assistenciais e operacionais calculados de forma descentralizada e sem curadoria.
- Uso limitado de dados para gestão de leitos, agenda e auditoria de contas.
